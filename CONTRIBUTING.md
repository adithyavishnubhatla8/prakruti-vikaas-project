# Contributing

Thanks for your interest in PRAKRUTI VIKAAS.

## Before contributing
- Read the project overview and architecture documents.
- Open an issue to discuss substantial changes.
- Keep farmer safety, data quality, privacy and offline behaviour in mind.

## Pull requests
- Describe the problem and proposed change.
- Include screenshots for UI changes.
- Add or update tests for behaviour changes.
- Document new API configuration without committing secrets.
- State which external integrations were tested and how.
- Separate verified outputs from estimates or demo data.

## Code quality
Follow the conventions already used in the Android project. Keep changes focused and avoid introducing unnecessary dependencies.
